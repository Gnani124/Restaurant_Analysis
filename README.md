# 🍽️ Restaurant Analysis Dashboard – Power BI Project

## 📌 Project Overview

This project presents a **Restaurant Analysis Dashboard** built using **Power BI** to analyze restaurant performance, customer ratings, voting patterns, pricing categories, and location-wise distribution. The dashboard provides interactive insights that help stakeholders understand restaurant trends, customer preferences, and business performance across multiple cities.

The solution consists of multiple report pages including:

* **Home Page** – Interactive navigation panel
* **Restaurant Performance Analysis**
* **Location-Wise Analysis**

The dashboard uses a modern dark-themed UI with dynamic filters, KPI cards, charts, maps, and detailed restaurant-level data.

## 📈 KPIs Included

| KPI               | Description                            |
| ----------------- | -------------------------------------- |
| Total Restaurants | Total restaurants available in dataset |
| Average Rating    | Overall customer rating score          |
| Total Votes       | Total customer reviews/votes           |
| Average Cost      | Average dining cost                    |
| Total Cities      | Number of cities analyzed              |
| Location Count    | Total locations covered                |

---

## 🎯 Business Insights Generated

* Most restaurants fall within the **3–4 rating range**
* Higher customer votes generally indicate better-rated restaurants
* Mid-range pricing categories dominate the market
* Metro cities contain the highest restaurant concentration
* Customer engagement strongly impacts restaurant popularity
* Pricing and ratings can be analyzed together for strategic decision-making
